## Caption

5 features I’d put in almost EVERY app 👇

1. Skeleton loaders: Show the structure of the screen while it loads instead of a spinning circle. It makes loading feel faster and looks way more polished.

2. Smart autofill: If your app already knows something about the user, don’t make them type it again. Prefill what you can and remove unnecessary friction.

3. Optimistic UI: Make actions feel instant. Update the UI immediately, process the request in the background, and only reverse it if something goes wrong.

4. Saved state: Don’t make users start over because they closed the app. Save unfinished forms, searches, filters, carts, drafts, and progress whenever it makes sense.

5. Proper error handling: Users should NEVER see a 404, 500, or random backend message. Preserve their progress, explain what happened, and give them a clear way to try again.
